# frases-inventario
Este repositorio contiene un archivo JSON con algunas citas, para ser utilizado en aplicaciones que las necesiten.

Si consideras que falta alguna, inclúyela. 

# Ejemplo de uso
Puedes generar frases al azar desde esta repo con la api `<% await tp.web.daily_quote("es") %>` en Obsidian con el plugin Templater
